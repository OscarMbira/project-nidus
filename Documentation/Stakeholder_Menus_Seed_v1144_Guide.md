# Stakeholder sample data for SEED334-PRJ-08 (v1144)

Sample rows for the Velocity Freight pilot so the Stakeholders menu is not empty.

## Pages covered

- Stakeholder Register
- Stakeholder Analysis
- Engagement Planning (one person in each board column: Leading, Supportive, Neutral, Unsupportive, Blocking)
- Communication Plans (three plans, plus three log entries on the Log tab)
- Assessment Matrix

## How to load it

1. In the Supabase SQL editor, run `SQL/v1144_seed_stakeholders_seed334_prj08.sql`.
2. In the app, select **Velocity Freight - Dynamic Route Optimization Pilot (SEED334-PRJ-08)**.
3. Open each Stakeholders link. Refresh if a page was already open.

The script is safe to run again. It only adds these rows for this project. Stakeholder reference numbers are assigned by Admin ID Generation (left blank on insert).
