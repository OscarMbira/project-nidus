# Simulator 5-Role System Guide (v734)

## The five practice roles

| Role | Level | Dashboard |
|------|-------|-----------|
| Project Coordinator | Beginner–Intermediate | `/simulator/coordinator/dashboard` |
| PMO Analyst | Intermediate | `/simulator/pmo/dashboard` |
| Project Manager | Advanced | `/simulator/pm/dashboard` |
| Programme Manager | Expert | `/simulator/programme/dashboard` |
| Portfolio Manager | Expert | `/simulator/portfolio/dashboard` |

## Getting started

1. Complete simulator onboarding (`SimulatorWelcome`).
2. Choose your role at `/simulator/role-selection`.
3. Enter your role dashboard from the switcher or role card.
4. Browse role-filtered scenarios at `/simulator/scenarios`.
5. Follow your learning path at `/simulator/learning`.

## Subscription tiers

| Tier | Roles |
|------|-------|
| Free | Project Coordinator |
| Basic | + PMO Analyst, Project Manager |
| Professional | + Programme Manager, Portfolio Manager |
| Enterprise | All roles + corporate features |

## Switching roles

Use the practice dashboard switcher or return to role selection. Progress is tracked per role in `sim.user_progress.preferred_role` and learning path tables.

## Deprecated

The Team Manager (`/simulator/tm/*`) dashboard is deprecated and redirects to role selection.
