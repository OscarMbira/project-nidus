# Project Nidus — Marketing, Advertising & Creative Services Menu Taxonomy

> **Recommended industry code:** `MKT`
>
> **Industry name:** Marketing, Advertising & Creative Services
>
> **Purpose:** Define a deep menu taxonomy for Project Nidus SaaS so Claude/Cursor can create or rationalise database-driven menus for marketing and creative organisations.
>
> This taxonomy should reuse existing generic Project Nidus capabilities wherever practical. It must not cause duplicate Risk, Cost, Approval, Testing, Procurement, Resource, Document, or Reporting engines simply because the marketing context uses different terminology.
>
> `CLAUDE.md`, `ROADMAP.md`, and `REVIEW.md` remain authoritative.

# 2. Reuse of Generic Project Nidus Capabilities

Claude should classify each proposed Marketing & Creative menu item before building anything.

Preferred classifications:

```text
A. Existing Generic PM Capability
B. Shared Capability with Marketing Configuration
C. Marketing-Specific Extension
D. Marketing-Specific New Capability
E. Reporting / Filtered View
F. Template / Workflow / Reference Data Only
```

Examples:

| Marketing capability | Preferred Project Nidus treatment |
|---|---|
| Marketing Risks & Issues | Reuse generic Risk / Issue engines with marketing context |
| Marketing Budget | Reuse generic Cost Management |
| Creative Resource Management | Reuse generic Resource Management where practical |
| Approvals & Governance | Reuse common approvals/governance engine |
| Agencies & Suppliers | Reuse procurement/vendor capabilities where suitable |
| Marketing Calendar | Reuse common calendar/scheduling capability where suitable |
| Campaign Schedule | Link to generic planning/scheduling capability |
| Campaign Deliverables | Reuse product/deliverable management |
| Marketing Assets | Reuse common document/asset/storage capability where suitable |
| Lessons & Knowledge | Reuse lessons/document/knowledge capability where suitable |
| Performance & Analytics | Extend common reporting/dashboard framework |
| Events & Activations | New domain capability only where existing event/project features are insufficient |

Do not create a separate marketing version of every generic PM module.

# 4. Menu UX Recommendation

The taxonomy is intentionally deep.

Do not necessarily expose all levels directly in the sidebar.

Recommended navigation mapping:

```text
Level 1 → Industry heading / major domain
Level 2 → Expandable sidebar group
Level 3 → Main page
Level 4+ → Tabs, sub-navigation, statuses, filters, or workflow sections
```

Example:

```text
Campaign Management
   ↓
Campaign Register
   ↓
Individual Campaign
   ├── Overview
   ├── Audience
   ├── Budget
   ├── Channels
   ├── Deliverables
   ├── Schedule
   ├── Approvals
   └── Performance
```

This is preferable to displaying every deep node simultaneously in the left navigation.

# 5. Claude Implementation Instruction

Before implementing this menu:

1. Read `CLAUDE.md`.
2. Read `ROADMAP.md`.
3. Read `REVIEW.md`.
4. Read the SaaS Industry Tenant Provisioning Revamp Brief.
5. Read the Core PM & Industry Menu Taxonomy.
6. Audit the existing menu records, modules, routes, tables, permissions, shared packages, and Admin configuration.
7. Map every menu item to one of:
   - existing capability
   - reusable capability
   - configurable capability
   - new capability candidate
   - backlog only
8. Do not create blank pages merely to satisfy the taxonomy.
9. Do not hard-code the menu in React.
10. Use the existing database-driven menu architecture.
11. Apply role, feature, subscription, organisation, and industry resolution.
12. Reuse generic PM modules wherever appropriate.
13. Create/update the PRD and implementation plan before significant new capability development.
14. Test direct-route/API authorization independently from menu visibility.
15. Review using `REVIEW.md`.

# 6. Final Principle

> **Marketing & Creative should be an industry capability pack on top of Project Nidus, not a separate PMIS.**

Use:

```text
Generic Project Management
+
Marketing-specific configuration
+
Marketing workflows
+
Creative production capabilities
+
Industry templates
+
Industry reporting
```

while keeping common project controls shared and authoritative.
