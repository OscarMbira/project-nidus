# Sidebar hide and show

The left menu can be hidden so a wide register or table can use the full page width.

## How to use it

On a wide screen, the control sits in the header, immediately to the left of the Project Nidus name.

- The panel icon means the menu is showing. Click it to hide the menu.
- The open-panel icon means the menu is hidden. Click it again to bring the menu back.

The choice is remembered in this browser, so the next page and the next visit keep the same setting. Phone and tablet still open the menu as a drawer over the page.

## Where it applies

Platform and Simulator pages that use the shared left menu, including Project Manager and PMO screens.
