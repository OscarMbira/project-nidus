## Design recap (see PRD §d for the full decision table)

- **Pattern to replicate everywhere** — the exact shape already proven on `IssueForm.jsx` (Platform + Simulator) and `OrganisationalTemplateDetailPage.jsx`:
  ```jsx
  <DetailAuditTabList activeTab={tab} onChange={setTab} tabs={[...]} />
  {/* or, for simple 2-tab forms: */}
  <DetailAuditTabList activeTab={tab} onChange={setTab} />

  {tab === 'audit' && (
    !record?.id ? (
      <p className="text-sm text-gray-500 dark:text-gray-400">Audit details appear after this record is saved.</p>
    ) : (
      <AuditDetailsPanel description="Who created or changed this record, and how it is classified.">
        <AuditCard title="Identity" description="...">
          <AuditField label="Display ID" value={...} />
          <AuditField label="Title/Name" value={...} />
          <AuditField label="Status" value={humanizeAuditToken(...)} />
          {/* + record_status for governed records */}
        </AuditCard>
        <AuditCard title="Classification" description="...">
          {/* type/category/tier/scope/project/owner — whichever apply */}
        </AuditCard>
        <AuditCard title="Record history" description="...">
          <AuditField label="Created by" value={auditUserLabels[record.created_by]} />
          <AuditTimestampPair dateLabel="Created at" value={record.created_at} />
          <AuditField label="Updated by" value={auditUserLabels[record.updated_by]} />
          <AuditTimestampPair dateLabel="Last updated" value={record.updated_at} />
          {/* + authorised_by/at, deleted_by/at where those columns exist */}
        </AuditCard>
      </AuditDetailsPanel>
    )
  )}
  ```
- **Shared components** (no change needed beyond the one already made): `AuditField`, `AuditCard`, `AuditDetailsPanel`, `AuditTimestampPair` — unchanged. `DetailAuditTabList` — generalised (see below).
- **User-label resolution**: reuse each form's existing `auditUserLabels`/`resolveAuditUserLabels`-style lookup where already present; add the same pattern (batch-resolve `created_by`/`updated_by`/etc. IDs to display names) where a form doesn't have one yet.
